# Wulfpack Forge banner asset

The approved Wulfpack Forge wolf banner is the canonical visual direction for this repository and application UI.

The binary banner image is maintained as `assets/wulfpack-forge-banner.jpg` in the branded documentation tranche. It should be used across the README and as the visual source for the in-app header treatment.

Brand hierarchy:

**Wulfpack Forge**  
*Character Editor for Valheim*  
**by Frostwulf**  
*Based on VikingEditor by miskamero*

Visual principles:

- icy, high-contrast Norse fantasy atmosphere
- wolf imagery as the primary identity marker
- restrained runic/forged-metal detailing
- charcoal, navy, silver, frost-blue, and subtle warm firelight accents
- product UI remains readable and functional; imagery supports the editor rather than consuming the workspace

The project remains unofficial community software and must not imply endorsement by Iron Gate Studio or Coffee Stain Publishing.
